This page uses the pattern most heroes with video use: <video autoplay muted loop playsinline>. Nothing in it is broken. It decides for the visitor: the video downloads and moves on every visit, loops for as long as the page is open, and takes no notice of a system that asks for reduced motion. The usual pattern has no pause button either; this demo adds one in the bar above so you can stop it.
